<h1>To install the project</h1>
<ul>
  <li>Create new NestJS Application using the command: nest new myapp</li>
  <li>Move to the [newapp] directory: cd myapp</li>
  <li>Install the following dependencies using npm install: @nestjs/mapped-types, class-validator, class-transformer, bcrypt</li>
  <li>Copy the the content of src folder from the repo to the local src directory</li>
</ul>
